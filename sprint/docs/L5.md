## 남은 확인 (사용자)
1. Grok에 MCP 등록: 주소 `https://meet.keyda.site/mcp`, Bearer 토큰 = 서버 `.env`의 `OWNER_KEY`
2. Grok에게 "다음 주 화요일 저녁 7시부터 10시 회의 등록해줘" → 휴대폰 캘린더에서 그날 저녁이 빗금으로 바뀌는지
3. 휴대폰으로 신청 1건(본인 이름) → Grok에게 "새 약속 있어?" → "수락해줘" → 휴대폰 "내 신청"에서 확정 → Grok에게 "그 약속 취소해줘"
