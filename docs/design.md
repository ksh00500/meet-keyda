# 디자인 지침 · 시호와 약속 잡기

화면을 고치거나 새로 만들 때 이 파일을 먼저 읽는다. AI가 작업할 때도 같다. 지침에 없는 결정을 했다면 여기에 한 줄 남긴다.

## 1. 누구를 위한 화면인가

- **친구:** 카카오톡 링크를 눌러 **휴대폰**으로 들어온다. 처음 보는 화면이고 설명을 읽지 않는다. 1분 안에 신청을 끝내야 한다.
- **주인(시호):** 신청을 확인하고 처리한다. 평소에는 Grok(MCP)으로 처리하고, 주인 화면은 확인용이다.
- **핵심 과업:** 빈 날짜 → 시간 → 이름·PIN → 신청. 이 흐름을 방해하는 것은 넣지 않는다.

## 3. 색 (사용자 지정 팔레트, 역할 고정)

| 토큰 | 값 | 쓰는 곳 | 쓰지 않는 곳 |
| --- | --- | --- | --- |
| `--cream` | `#FFEFD2` | 화면 바탕 | 글자 |
| `--teal` | `#6AB0AF` | 주 버튼, 선택한 날짜·시간, "확정" | 글자색(크림 위 2.2:1). 장식 |
| `--salmon` | `#F5A89A` | "불가" 빗금 | 경고 외의 장식 |
| `--lemon` | `#FFF2A5` | "신청 중", 내 신청 표시 | 일반 강조 |
| `--ink` | `#1F2A2A` | 글자, 청록 버튼 위 글자(5.9:1) | - |
| `--teal-deep` | `#2E6E6D` | 링크·청록 계열 글자(크림 위 5.2:1) | 넓은 면 |
| `--surface` | `#FFFAF0` | 카드·시트 바탕 | - |

규칙
- 흰 글자를 청록 위에 올리지 않는다 (2.5:1, 불합격).
- 상태는 색만으로 구분하지 않는다. 불가 = 빗금, 예약됨 = 회색 면, 신청 중 = 레몬 + 글자.
- 상태색(살몬·레몬)을 장식에 쓰지 않는다. 청록은 화면마다 주 행동 하나에 쓴다.
- 이 팔레트(크림 + 따뜻한 포인트)는 AI 디자인의 흔한 조합과 비슷하다. 그래서 개성은 색이 아니라 **캘린더 자체(하루 막대, 빗금)와 문구**로 낸다.

| 누르는 영역 | 최소 44×44px. 날짜 칸 사이 간격 4px 이상 |

## 5. 화면 흐름 (친구)

```text
캘린더 ──날짜 누름──▶ [시트] 1. 시간 고르기 ──다음──▶ 2. 이름·PIN·메모 ──신청하기──▶ 3. 완료
                                ▲                        │
                                └────── 시간 바꾸기 ──────┘
```

- 휴대폰: 시트가 아래에서 올라온다. 넓은 화면(960px 이상): 오른쪽 고정 패널.
- 단계마다 행동은 하나. 주 버튼은 시트 아래에 고정, 높이 52px, 폭 전체.
- 버튼 문구는 결과를 말한다: "이 시간으로 다음" → "신청하기" → 완료 "신청했어요".
- 완료 화면: 신청 내용, "확정되면 여기서 보여요", 다른 기기에서는 이름 + PIN으로 찾을 수 있다는 안내.

## 6. 캘린더 칸

칸 아래에 **오전(09–13) · 오후(13–18) · 저녁(18–22)** 세 칸을 둔다. 비율 막대보다 "언제 되는지"가 한눈에 읽힌다.

| 세 칸 표시 | 뜻 |
| --- | --- |
| 청록 꽉 참 | 그 구간 전부 가능 |
| 옅은 청록 + 테두리 | 30분 이상 빈 시간이 있음 (일부 가능) |
| 살몬 빗금 | 불가 |
| 회색 | 예약됨 |

| 칸 상태 | 모양 | 누름 |
| --- | --- | --- |
| 가능 | 흰 칸 + 요약 글자("종일 가능", "저녁 가능", "오전·오후 가능", "일부 시간 가능") + 세 칸 | 가능 |
| 불가 | 옅은 살몬 칸 + "불가" + 빗금 세 칸 | 불가 |
| 신청 기간 아님 | 숫자만 흐리게 | 불가 |
| 내 신청 있음 | 숫자 옆 점 (레몬 = 신청 중, 청록 = 확정) | 가능 |
| 오늘 | 요약 대신 "오늘" | 불가(당일 신청 막음) |

좁은 휴대폰(560px 미만)에서는 요약 글자를 숨기고, 세 구간을 위아래로 쌓아 칸 폭만큼 긴 막대 세 줄로 보인다(위부터 오전·오후·저녁). 가로로 세 칸을 두면 칸이 좁아 동그라미처럼 보이기 때문이다. 위에 범례 한 줄로 뜻을 알려 준다.

## 6-0. 주간 보기

- 캘린더 위 "월간 · 주간" 전환. 고른 보기는 그 브라우저에 기억한다.
- 하루가 한 줄: 왼쪽 날짜·요일, 오른쪽 요약 글자와 08–23시 막대(눈금, 불가 빗금, 예약됨 회색, 빈 곳은 흰색). 맨 위에 9·12·15·18·21시 눈금 한 줄.
- 줄을 누르면 월간과 같은 날짜 시트가 열린다. 휴대폰 세로 화면에서 하루 시간을 가장 자세히 보는 방법.

## 6-1. 하루 시간 막대 (날짜 시트)

| 요소 | 규칙 |
| --- | --- |
| 범위 | 기본 08–23시. 고른 시간이 밖으로 나가면 넓힌다 |
| 높이·눈금 | 막대 48px. 1시간마다 옅은 선, 3시간마다 진한 선과 "9시·12시…" 표시 |
| 구간 | 불가 = 살몬 빗금 + "불가", 예약됨 = 회색 + "예약됨" (폭이 좁으면 글자 생략) |
| 고른 시간 | 청록 상자, 막대 위에 "16:00–17:00" 하나로 표시 (두 시각을 따로 띄우면 겹침) |
| 빈 곳 누르기 | 누른 위치를 30분 단위로 반올림한 시각부터 1시간 (빈 구간 끝을 넘지 않음). 막힌 구간은 반응 없음 |
| 빈 시간 목록 | 막대 아래 "빈 시간" 알약 버튼. 손가락으로 막대를 정확히 누르기 어려울 때와 화면 낭독기용 |
| 마우스 올림 효과 | `(hover: hover)`인 기기에서만. 휴대폰에서 눌린 색이 남지 않게 |

## 7. 문구

- 해요체, 짧게. 사용자가 아는 말로: "토큰" ✕ → "이 기기".
- 오류는 원인과 고치는 법: "PIN은 숫자 4자리예요".
- 빈 화면은 다음 행동을: "아직 신청한 약속이 없어요. 캘린더에서 날짜를 골라 보세요".
- 같은 행동은 같은 이름: 신청하기 → 신청했어요 → 신청 중.
- 정보 줄을 가운뎃점(·)으로 길게 잇지 않는다. 날짜와 시간은 줄을 나눈다.

## 8. 움직임

- 저절로 움직이는 연출 없음. 시트 열기와 신청 완료, 두 가지 반응만.
- `prefers-reduced-motion`이면 모두 끈다.
